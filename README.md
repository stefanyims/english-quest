# English Quest — versión corregida de prueba

## Cómo abrirla
1. Descomprime el ZIP.
2. Abre la carpeta `English_Quest`.
3. Haz doble clic en `index.html` para abrirlo en Chrome.

## Cambios de esta versión
- Ahorcado: las pistas describen la palabra en español sin decir la respuesta; sesiones de 20 palabras.
- Crucigrama: cuadrícula de palabras cruzadas, pistas en español, numeración, selección de categoría y control de cantidad.
- Memoria: cada pareja consiste en una palabra en inglés y su traducción en español. Las tarjetas están ocultas al inicio; los colores se asignan independientemente de las parejas para no revelar la respuesta. Las parejas incorrectas vuelven a ocultarse.
- Letras revueltas: se muestra el significado en español y la persona escribe la palabra en inglés.
- Construir frases: selector de Principiante, Intermedio y Avanzado; al acertar se muestra la traducción.
- Descubrir mi nivel: 25 preguntas variadas por intento, equilibradas entre dificultades y con gramática, vocabulario, lectura y situaciones contextualizadas; resultado global y desglose por dificultad.
- Sin reproducción de audio ni juego de Emparejar palabras.

## Limitaciones importantes
Este es un prototipo local para pruebas, no una aplicación comercial lista para publicar. El banco de vocabulario actual es limitado y no contiene todavía 5.000 ejercicios únicos, revisados y distintos por juego. El test es orientativo, no una certificación oficial; no evalúa comprensión auditiva ni pronunciación. Antes de vender la aplicación hay que ampliar y revisar profesionalmente el contenido, probarla en distintos equipos y preparar la publicación.
