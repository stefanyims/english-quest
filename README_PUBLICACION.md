# English Quest — paquete web inicial (PWA)

Este paquete añade un manifiesto, iconos SVG y un service worker al prototipo HTML recibido. Es una preparación técnica inicial, NO una versión certificada ni comercial lista para Microsoft Store.

## Próximo paso
1. Subir el contenido de esta carpeta a un repositorio GitHub.
2. Activar GitHub Pages para servir el sitio por HTTPS.
3. Probar el sitio publicado en Chrome/Edge y corregir fallos.
4. Usar PWABuilder para analizar/empaquetar la PWA y seguir las instrucciones actuales de Partner Center.

## Límites actuales
- No incluye registro de usuarios, backend ni suscripciones/pagos.
- El contenido de los juegos sigue siendo el del prototipo recibido y no está validado comercialmente.
- Los iconos SVG pueden requerir conversión a PNG para determinados validadores/paquetes.
- El service worker es básico y debe probarse en el alojamiento real.
